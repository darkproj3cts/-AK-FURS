## Грязь в данных

### Статусы CRM (14 → 4)
- Оплачен: `Оплачен`, `Оплачен ` (пробел), `оплачено`, `PAID`
- Отменён: `Отменён`, `отменен`, `CANCELLED`
- Возврат: `Возврат`, `возврат`, `REFUND`
- В работе: `В работе`, `в работе`, `NEW`, `Ждём оплату`

### Форматы дат в CRM
- ISO `2026-03-03` (536 строк)
- DD.MM.YYYY `09.01.2026` (448 строк)
- DD/MM/YYYY `31/10/2025` (215 строк)
- Excel serial `45752` → база 1899-12-30 (123 строки)
- Русский текст `23 сен 2026` (~130 строк)

### Цены в CRM
- Пробел как разд. тысяч: `50 000`, `2 200 000`
- Запятая = разд. тысяч + точка = десятичный: `17,000.00`, `245,000.00`
- Запятая = десятичный: `140000,00`
- Миллионы: `2,48 млн` (единственный случай)

### Скидки
- `7%`, `5%`, `3%`, `10%` — процент от суммы строки
- `800`, `1 000`, `1,000.00` и т.д. — рублей на строку

### Номера заказов в CRM
- `A-00XXX` (5 цифр с ведущими нулями) — основной формат, 825 строк
- `A00XXX` (без дефиса) — 238 строк
- ` a-NNN` (пробел + строчная + короткий номер) — ~232 строки
- Встречается кириллическая `А` вместо латинской `A`

### Менеджеры
- Пробел перед именем: `' В. Белова'`
- Пробел после имени: `'полина орлова '`

### Назначения платежей (банк) — 7 форматов
| Пример | Что означает |
|---|---|
| `A877 доплата` | заказ 877 |
| `Предоплата заказ 775, тел. ...` | заказ 775 |
| `зак. 528` | заказ 528 |
| `Оплата заказа A-00243` | заказ 243 |
| `Оплата по заказу А-00391 (шуба)` | заказ 391 (кириллическая А) |
| `по счету №828 от ...` | заказ 828 (счёт = заказ, 173/173 совпали) |
| `Счёт № 00991 от ...` | заказ 991 (то же) |
| `Оплата по договору` | нет номера → неопознанный |

### Возвраты в выписке
`Возврат денежных средств по заказу A-00775` → Тип = `Списание` → в Q2 не считать.

### Дубли в CRM
- 56 пар с дублирующимся (заказ, № строки)
- 26 из них с одинаковым `Выгружено` — полные дубли (все поля совпадают)

### Форматы цен в чатах
- `53 000 ₽`, `138 тыс.`, `2,404 млн`
- `сто пятьдесят восемь тысяч рублей`
- `два миллиона двести тысяч рублей`
